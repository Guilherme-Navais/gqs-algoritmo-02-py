**NÍVEL 1**

**Como executar?**
Para executar basta ter o python instalado na máquina.
É necessário navegar pelo cmd até a pasta que o arquivo do código está, e depois executá-lo com o comando abaixo:

```bash
python Números primos 2.0.py
```

**NÍVEL 2**

**O que o código faz?**
O programa postado pede para o usuário inserir um número inteiro e informa se o número digitado é um número primo ou não

**Detalhamento do código:**
As principais funções utilizadas foram "if", "while" e "def"

**Exemplo de saída:**
```bash
Digite um número inteiro: 13
13 é um número primo!

Digite um número inteiro: 8
8 não é um número primo

Digite um número inteiro: 0

Encerrando programa...
```
